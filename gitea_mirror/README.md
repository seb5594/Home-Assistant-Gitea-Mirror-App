# Gitea Mirror

Mirrors repositories from GitHub, GitLab or another Gitea to your own Gitea and keeps them up to
date, with the original web interface inside Home Assistant.

* The web interface opens in Home Assistant and signs you in with your account.
* The address of the [Gitea app by alexbelgium](https://github.com/alexbelgium/hassio-addons/tree/master/gitea)
  is already filled in; you add the access tokens.
* Every environment variable of Gitea Mirror is an option, in English and German.
* Pinned to a released version and updated by itself when the original project publishes one.

> **Pre-release.** This is an Alpha version. Please report what you see.

Open the *Documentation* tab for setup, options and troubleshooting.
